# RSNA Knee 2026 — Phase 0 artifacts

Derived from the competition training data. Private. Regenerated by code at
<https://github.com/homeshwarnelakurthi/RSNA-Knee-Abnormality-Detection>.

| File | Rows | What |
|---|---|---|
| `series_meta.csv` | 24,386 | One row per series. Header-only DICOM scan of all 819,078 files: geometry, scanner identity, sequence parameters, slice counts. Produced by the `rsna-knee-phase-0-metadata-scan` kernel. |
| `weak_labels_v1.csv` | 4,407 | Report-derived targets. Per label: `sev::` soft severity target in [0,1], `pres::` binary presence control, `conf::` confidence weight. Plus `side_from_report`. |
| `laterality_sources.csv` | 4,407 | Per study: DICOM tag, report-derived side, geometry-derived side, and image-centre x. |
| `b4_eval_v1.csv` | 12 | Presence vs severity extractor AUC on the 58 gold-labelled studies. |

## Notes

- **`sev::` columns are soft targets, not probabilities.** The competition metric is
  rank-based AUC, so these encode severity ordering rather than calibrated likelihood.
- **`conf::` should be used as a per-sample loss weight.** It is low where the report is
  short or the finding was hedged. Roughly a third of Croatian/Flemish and Spanish
  reports run under 50 words and do not list negatives, so "not mentioned" is not
  reliably a negative in those.
- **Laterality:** ship `tag` when present, else geometry. Geometry agrees with
  report-derived side 98.9 % on Siemens, 96.2 % Philips, 92.6 % GE, 87.3 % Toshiba.
  Hitachi (n=8) looks inverted but the sample is too small to act on.
- No report text is included in any file.
